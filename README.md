# 🌐 Nuril Portfolio Website

Personal portfolio website yang dibuat untuk menampilkan profil, skill, dan project dengan desain modern, responsif, dan interaktif.

## 📌 Fitur Utama

* ✨ Tampilan modern & responsive (mobile-first)
* 🎨 UI/UX clean dan interaktif
* 🧑‍💻 Section About Me
* 🛠️ Skills & Technologies
* 📂 Portfolio / Projects showcase
* 📞 Contact form
* 🎯 Animasi hover & transition

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* (Optional: Tailwind / custom CSS styling)

## ⚙️ Cara Menjalankan Project

1. Clone repository:

```bash
git clone https://github.com/KangBasrengg/Nuril-Portofolio.git
```

2. Masuk ke folder project:

```bash
cd Nuril-Portofolio
```

3. Jalankan di browser:

* Klik 2x `index.html`
  atau
* gunakan live server di VS Code
